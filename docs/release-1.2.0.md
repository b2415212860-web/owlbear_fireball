# 1.2.0 实施与验收记录

日期：2026-09-06。状态：Owlbear 专用本地候选版；未推送 GitHub、未部署服务器，真实房间验收尚未完成。

## 这次完成了什么

保留原生 20 英尺瞄准圈、角色棋子发射起点、右上角按钮、多人事件和恢复流程，替换房间内实际调用的 Three.js 渲染核心。生产包只包含后台、按钮和透明特效页，直接访问扩展首页仅显示安装提示，不附带网页演示。

视觉时间线为约 0.9 秒圆形火球飞行，命中后约 3.8 秒爆炸和消散：

- 圆球表面是流动的三维湍流火焰，外侧柔软火舌，后方连续拖尾；没有把球头拉成长条。
- 命中瞬间高速膨胀的热焰团与短暂局部闪光，随后压力/尘埃冲击波向外推出，火星四散。
- 蘑菇云采用有密度和遮光变化的局部体积光线步进；俯瞰视角下可见云帽升起、翻卷、冷却消散，保留紧凑范围。它不是完整流体物理模拟。
- 没有全屏 Bloom、地面裂缝、永久残留、伤害结算或音效。

## 性能与生命周期

| 项目 | 标准 | 低配 |
| --- | --- | --- |
| 火星 / 合批尾焰段数 | 320 / 32 | 120 / 16 |
| 画布最大内部尺寸 | 1280×720 | 960×540 |
| 体积步数 | 20 | 10 |
| 放大时内部爆炸像素半径上限 | 300 | 220 |

画布不跟随设备高 DPI 增倍。地图放大只降低内部采样密度，不缩小世界坐标中的 20 英尺范围；小幅连续缩放也会累计触发像素预算调整。烟云共享 32 KiB 三维噪声纹理，云形运动参数每帧计算一次，通过复用的 uniform 向量传入 GPU；不是在每个体积采样点重复计算云瓣轨道。

自动画质根据近期慢帧降档，当前客户端保留 60 秒降档记忆；手动画质选择优先。每客户端最多一个 Three.js 主效果和一个 Canvas 次效果，其他并发省略视觉并提示。WebGL 初始化失败使用 Canvas 后备，其视觉不是同等质量的三维效果。

后台没有逐帧动画或逐帧 SDK 场景写操作。瞄准更新最高 20Hz，播放中的视口投影采样最高 10Hz、单批在途。按次创建可见透明特效页，先预热，再确认实际首帧，最后广播施法。动画结束、取消或场景失效会清理播放；退出释放几何体、材质、三维纹理和 WebGL 上下文。空闲无特效渲染循环。

## 本地验证结果

- TypeScript 类型检查通过。
- `npm test`：105 项通过；`npm run test:deployment`：6 项通过，合计 111 项、0 失败。
- 模拟回归覆盖首帧/命中/结束时序、超时与取消、场景隔离、广播去重、并发上限、画质反馈和记忆过期、投影单在途、缩放像素预算。
- 实际浏览器加载生产渲染模块，检查圆球拖尾、命中和烟云。优化后的标准与低配体积着色器均实际绘制，相关浏览器警告/错误日志为空。
- 在 1280×720 本地检查窗口，低配、屏幕半径 600 的场景内部画布为 469×264，验证了缩放预算；这不是 Owlbear 房间帧率测试。
- `/fireball/` 子路径生产构建通过，校验 manifest、三个 HTML 入口及资源。没有 demo 或测试页生产入口。
- Three.js 效果 chunk 约 544 KB（gzip 139 KB），构建仍有超过 500 KB 的体积提示，不是失败。此资源只在可见特效页使用；冷启动仍需要下载和编译时间。

开发回归页 `tests/render-fixture.html` 仅供检查确定性关键帧，不进入部署包，也不替代真实房间验收。模拟 SDK 测试无法证明宿主模态层兼容性。

## 发布前必须在测试房间检查

- [ ] 同版扩展安装、GM 初始化场景；选中单个角色图像棋子后，右上角按钮正常。
- [ ] 20 英尺半径等于四个 5ft 格；不同 DPI、米制及缩放/平移后定位准确。
- [ ] 首次冷加载与连续 20 次施法均完整完成飞行、命中、冲击波和消散；无锁死或临时图元残留。
- [ ] 播放期间地图拖动、缩放、键盘快捷键、Esc 和其他扩展弹窗不被透明模态层破坏。
- [ ] 两个客户端不同视角和同时施法；第三次并发被合理省略，迟到客户端不重播旧施法。
- [ ] 切场景、隐藏标签页、断网、WebGL 丢失、恢复按钮；旧效果不会在新场景出现。
- [ ] 在目标设备记录 Owlbear 空闲基线及特效期间帧时间，检查自动降档、低配和回收后资源；不以独立画布结果承诺房间 FPS。
- [ ] 公网与 Docker 容器内 manifest 均为 1.2.0，fx.html 可加载，CORS 和 iframe 响应头允许 Owlbear，CDN 与旧客户端已刷新。

若透明模态层影响关键地图交互，必须调整承载方案再发布，不能仅因本地画面成功而声称已经兼容。部署步骤与回滚注意事项见根目录 README。
