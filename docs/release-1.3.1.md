# 1.3.1 · 轻量电影化爆炸

## 修改范围

仅修改 Owlbear 生产渲染路径，保留圆形 3D 球头、20 英尺瞄准圈、向左偏移 100px 的面板和残留 Props。没有改成预渲染素材，没有发布演示页，也没有增加全屏 Bloom、震屏、声音、地面裂缝或物理规则。

- 命中后停止发射尾焰，已存在的尾焰在原轨迹上膨胀、冷却并于 0.32 秒内淡出，不再瞬间消失或越过目标。
- 爆炸开头是局部白黄短闪和高速膨胀的火焰；纹理随气团扩张并撕裂，火团在 0.72 秒前淡出。
- 尘浪延后 0.12 秒开始，用不规则方向分区、颗粒密度和局部缺口替换完整发光圆环，1.12 秒前消失。
- 七个体积烟团各有大小、位置、高度、翻卷速度，仍是高角度俯瞰云帽与短烟柱。内部热区由烟雾前后层遮挡；末期先在稀薄区域侵蚀，再整体淡出。
- 原粒子预算内区分短寿命火星和较重余烬；只有少量火星高速飞出，余烬减速下落、由亮变暗，2.2 秒前消失。粒子遮挡是局部视觉近似，不读取地图深度。
- 现有 cast-v2 的 seed 传到渲染器，按施法生成一次形态参数；同 seed、同动画年龄的形状可复现。不同设备/画质不是像素级一致，也没有改变原来的多人播放时钟。
- Canvas 后备保留简单画风，同步支持尾焰耗散、断续圆弧和种子变化，不尝试实现体积光照。

## 保留的性能约束

- 标准 320 火星/余烬 + 32 尾焰，低配 120 + 16；最大内部画布分别为 1280×720 和 960×540。
- 体积烟雾仍用 32 KiB 三维噪声纹理，标准 20 步、低配 10 步；仅覆盖局部命中区域。放大地图时内部像素半径仍封顶 300 / 220。
- 不新建全屏中间缓冲。命中初期因为保留旧尾焰，最多五个局部绘制调用同时存在，0.32 秒后尾焰退出。
- 继续复用场景、材质、几何和噪声纹理；形态参数仅在 seed 变化时重新计算，不为每帧或每个烟雾采样创建对象。
- 0.9 秒飞行 + 3.8 秒爆炸/烟雾，总流程不延长；原有自动降档、首帧/命中/结束确认、取消、超时、场景隔离和结束后生成 Props 不变。

## 验证

自动回归覆盖形态可复现、seed 经播放/投影传递、尾焰衔接、分层退出、紧凑体积边界、GPU 对象复用和两档预算，并继续覆盖原有场景生命周期、原生瞄准及残留对象逻辑。

本次 TypeScript 检查、167 项单元/回归测试、6 项部署测试通过。本地 4173 安装入口返回 HTTP 200、manifest 1.3.1，并允许 Owlbear Origin 的 CORS。构建仍提示 Three.js 主特效 chunk 大于 500 kB（本版约 547.45 kB，gzip 140.81 kB）；这是体积提示，不是构建失败，也不代表运行帧率。

本地浏览器的 `tests/render-fixture.html` 用实际生产 Three.js 渲染器检查飞行、命中、尘浪、烟云和淡出，包含标准/低配、明暗背景和不同 seed。该页面只用于开发回归，不进入 dist。此检查不是在真实 Owlbear 房间里进行，独立页面计时不能视为整个 Owlbear 的 FPS；部署后仍需多客户端、移动/缩放地图和低性能设备验收。

标准及低配各一次完整浏览器播放都按 `started → impact → finished` 收尾，所有可见特效层在结束后隐藏，检查时未发现浏览器警告或错误。冻结帧检查包括飞行 0.70 秒、命中后 0.14 秒、烟云阶段和总时间 4.62 秒的最终淡出。

## 更新安装

1. 备份旧版本。将部署包 `dist/` 内的文件更新到服务器现有 `/opt/owlbear_fireball/dist/` 内，不要再套一层 dist，也不要整体改名替换 Docker 已绑定的目录。
2. 先传 assets，再传 HTML 和 manifest；保留旧哈希资源供尚未刷新的客户端使用。
3. 清理 CDN `/fireball/` 缓存，确认 manifest 显示 `1.3.1`。无需改变原有挂载、域名或 Nginx location。
4. 安装地址仍是 `https://www.longtrail.cloud/fireball/manifest.json`；在 Owlbear 强制刷新/重新启用，各观看端都更新。
5. 选角色 → 点击火球术 → 移动范围 → 点击地图释放。确认尾焰连续、目标位置正确，烟雾正常结束后才生成已配置的 Fire Sphere；取消或失败时不生成。

只有本地源码和构建产物已更新，不代表已推送 GitHub 或已部署到服务器。
