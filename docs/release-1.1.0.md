# 1.1.0 实施与验收记录

日期：2026-09-05。状态：本地候选版，未推送 GitHub、未替换线上文件。

## 已实施

原生本地范围圈、严格角色棋子起点、20 英尺单位换算、Esc/切工具取消、场景和异步操作失效保护；同一套轻量 Three.js / Canvas 渲染器同时服务网页与 Owlbear；透明可见动画页先预热再确认首帧；本地和房间分频道；重复消息/错误来源过滤；旧场景不重播；异常提示、恢复按钮和资源清理。

采用按次打开的透明模态页，而不是常驻全屏模态。设置 `disablePointerEvents` 不等于已证明键盘焦点、其他模态和其他扩展均兼容。

并发预算收紧为 1 个完整效果 + 1 个轻量 Canvas 次效果，更多事件不排队重播。随机种子保留在消息协议里，目前粒子布局是固定可重复布局，并未实现按每条消息 seed 重排。

## 已做验证

- TypeScript 类型检查、Vite 子路径生产构建。
- `npm test`：91 项通过；`npm run test:deployment`：6 项通过；合计 97 项，0 失败。生产构建的 Three.js 效果 chunk 约 533KB（gzip 135KB），Vite 给出体积提示，不是构建失败；该 chunk 不在隐藏后台的动画路径中加载。
- 真实生产模块 + SDK/渲染器模拟测试：瞄准、控制器、播放适配器、去重和几何换算；包括迟到响应、首帧确认、失败不广播、准备时取消、投影单在途和关闭清理。
- 本机浏览器网页：显示 WebGL 已就绪；捕获实际立体火球飞行、命中冲击波/火星画面；低配 WebGL 连续 3 次均显示“烟尘散尽”并恢复按钮，捕获的浏览器 warning/error 日志为空。
- 实际共享渲染器基类和 Canvas 的模拟时钟回归：首帧延迟不跳过飞行、首帧成功后才广播、暂停/超时/隐藏取消、自动降档和空闲无 rAF。该组不创建真实 WebGL context。
- 构建后的 4173 预览：标准 WebGL 预热成功，Esc 取消和完整释放恢复按钮正常，warning/error 日志为空。本地 manifest / fx.html 返回 200，manifest 版本 1.1.0，预览服务器返回 Owlbear CORS 允许头。

模拟测试不是真实 SDK 集成测试；网页成功也不能代替房间验证。没有声称达到 50/30 FPS、没有完成移动设备压力测试。
