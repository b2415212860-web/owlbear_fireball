# 1.2.1 初始化诊断补丁

日期：2026-09-06。范围：本地代码、构建和预览服务；未推送或部署公网。

用户在 Owlbear 房间看到“火球术初始化失败，请重新启用扩展”。这条提示出自背景页的 SDK ready 回调之后，可以排除背景代码完全没执行，但仍可能是动态控制器资源加载失败，或某个 SDK 初始化步骤失败。Three.js 此时尚未启动，不能把这条错误归因于烟云性能。

已修改：

- 通知和控制台包含版本、失败步骤及原始错误，区分控制器资源加载、玩家连接、按钮、瞄准工具和场景读取。
- SDK 返回的普通 `{ message }` / `{ error }` 对象也保留错误文字，而不是 `[object Object]`；通知长度有限，完整错误保留在控制台。
- 忽略重复 ready 回调；通知本身发送失败也有 catch。
- 将退出清理安装到首次按钮 RPC 之前，初始化失败立即解除广播和场景监听、定时器并关闭本扩展按钮，避免留下半初始化状态。

TypeScript 检查及 116 项单元/模拟测试通过；另有 6 项子路径部署测试。新增回归覆盖各初始化边界失败及清理、动态 import 失败、原始错误展示和重复 ready。测试不替代真实 SDK 集成。

当前尚未确定用户此次失败的具体底层原因。请刷新 Owlbear 房间并重新启用同一本地扩展，回传带 `1.2.1` 的完整新提示。若仍只有旧通用通知，先确认实际加载的版本；不要同时启用公网旧版与本地候选版，也不需要全局关闭浏览器安全机制。

旧 `owlbear-fireball-1.2.0-candidate.zip` 是历史部署包，不包含本补丁；当前补丁在项目的 dist 中。
