# 1.3.0 · 可选残留素材

## 使用

1. 更新完整 dist，清除 CDN 的 `/fireball/` 缓存，在 Owlbear 房间强制刷新或重新启用扩展。
2. 确保场景已打开，点击火球面板下方“选择残留素材”，从 Owlbear 素材窗口选择 Fire Sphere。
3. 看到“残留：Fire Sphere”后，选角色棋子 → 火球术 → 移动鼠标 → 点击地图。
4. 等待飞行、爆炸、冲击波、烟雾正常结束，命中点生成独立的共享 Props。
5. 素材大小沿用素材库默认值。用 Owlbear 常规操作缩放或删除。“关闭”只停用后续生成，不删除既有对象。

首次只实现素材库选择方式；不包含场景模板捕获，也没有自动消失计时器。每个浏览器/房间独立记住选择，其他施法者需自行配置；这不影响其他玩家看见已生成的共享道具。扩展地址从 localhost 换为服务器地址时需重新选择。

## 实现

部署包内 `dist/` 的内容应上传到宿主机 `/opt/owlbear_fireball/dist/`，最终文件是 `/opt/owlbear_fireball/dist/manifest.json`，不要额外套一层 dist。先备份旧文件，先上传 assets 再更新 HTML 和 manifest，并保留旧哈希资源以兼容未刷新的客户端。保持原有 Docker 目录绑定及 Nginx `/fireball/` 配置，只更新目录内文件；不要整体改名替换已绑定的宿主机目录。安装地址仍是 `https://www.longtrail.cloud/fireball/manifest.json`。

- 施法创建 Job 时保存模板快照，只为本地发起的 Job 保存，不在房间动画消息中携带模板或创建命令。
- 只有正常 `finished` 且已收到 `started`、`impact` 才生成。终态处理先同步移除 Job，再异步创建；重复终态不能创建第二份。
- 道具 ID 使用本次施法 UUID，写入前检查 ID 是否存在，不覆盖已有对象。模板不复制任何其他扩展的 metadata、附件或原对象所有权。
- 创建前检查场景就绪、代次、场景标识和玩家 Props 创建权限。无权限时提示，不使用 GM 客户端代写，不重放火球。
- 模板只保存必要的媒体 URL、尺寸、DPI、缩放、旋转、名称，并对持久化数据做有界校验。HTTP(S) 图片/视频可用；不持久化 blob 链接。
- 一次共享对象写入，新增功能没有 RAF、轮询、自动删除或周期性 SDK 更新。循环动画素材自身仍有渲染开销。
- 悬浮 UI 保持向左 100 CSS 像素的偏移；面板高度增至 188 像素以容纳设置。

## 验证与限制

自动化覆盖正常结束、取消、错误、超时、重复消息、远端不创建、权限拒绝、写入失败、已存在对象不覆盖、选择取消、场景切换/页面关闭、存储失效与无效素材，以及面板交互。构建检查覆盖 `/fireball/` 下所有生产入口和引用资源。独立浏览器只检查生产按钮页面的排版，不等同于真实房间素材选择和跨客户端验收。

本次已通过 161 项单元/回归测试、6 项部署测试及 TypeScript 检查。生产包 manifest 为 1.3.0，本地安装链接 HTTP 200，并保留 Owlbear Origin 的 CORS 响应。

SDK 的 addItems 没有绑定场景 ID 的事务参数或撤销在途请求能力。代码会在异步读取之间和发送写入前再次检查场景；已发送的写入无法中止，也不自动向新场景重试。用户在最终 RPC 瞬间切场景仍存在宿主端竞态，需要真实房间验收，不能宣称跨场景原子性。

如果页面在动画结束前关闭、后台被挂起取消或播放失败，不生成残留，也不会重连补生成。各客户端动画不是严格同步时钟，残留出现时间由施法者正常结束决定。

尚未验证用户实际 Fire Sphere 素材的中心留白、默认比例、素材 CDN 可达性或真实多人房间性能；部署后应实测。
